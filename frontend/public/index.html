FAQ

Questions, answered.

Open an issue
Does my code leave my machine?

With the GitHub Action, your code stays in your own CI. The dashboard clones repositories with open pull requests to DocGuard’s server to check them. DocGuard never uses paid AI APIs, and the model runs on hardware we control.

What does it check today?

Python code against Markdown and reStructuredText docs. Changelogs and migration guides are skipped, because old values belong there.

Will it block my pull requests?

No. It reports what it found and leaves the decision to you.

Why does sign-in ask for GitHub access?

To list your repositories and pull requests. Public access is the default, and private access is only requested if you choose it.

How does it avoid false alarms?

A sentence is only reported when there is evidence the change made it wrong. A matching number or a mention of the setting isn’t enough.
