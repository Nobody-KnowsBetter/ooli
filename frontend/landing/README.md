# Kaviyan - AI Video Studio Website Clone

A complete, pixel-perfect, self-contained clone of [kaviyan.framer.website](https://kaviyan.framer.website/) as of October 2026.

---

## 🚀 Quick Start

Run the site locally with **Node.js**:

```bash
npm start
```
or
```bash
node server.js
```

Then open your browser at **[http://localhost:3000](http://localhost:3000)**.

Alternatively, you can use Python or any static web server:

```bash
# Python
python3 -m http.server 3000

# or npx serve
npx serve . -p 3000
```
