# 💻 DocGuard Frontend Dashboard

Modern, responsive Next.js dashboard for real-time documentation intelligence and drift management.

## 🚀 Getting Started

### Prerequisites
- Node.js 18.x or later
- npm or pnpm

### Installation
```bash
npm install
```

### Running Locally
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🛠️ Features
- **Overview Analytics**: Live documentation health score, drift count, and repository metrics.
- **Drift Explorer**: Filter and inspect documentation drifts with AST code vs doc evidence side-by-side.
- **One-Click Autofix**: Interactive diff preview and patch application.
- **Repository Management**: Connected repositories and scan triggers.
- **Scan History**: Full audit trail of past PR scans and verification verdicts.
